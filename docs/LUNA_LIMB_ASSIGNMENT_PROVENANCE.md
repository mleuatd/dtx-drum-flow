# Luna say maybe — Limb Assignment Provenance

Updated: 2026-09-20

## What is externally authoritative

- Drum note/instrument placement is based on the Songsterr drum chart already used by the project:
  https://www.songsterr.com/a/wsa/luna-say-maybe-drum-tab-s1089457
- The original recording credits Takashi Kashikura / 柏倉隆史 on drums.
- A public performance cover by miyako explicitly states that it aimed for a complete copy of Kashikura's playing:
  https://www.youtube.com/watch?v=ntddGdtdrsc
- Another public ear-copy / performance log exists:
  https://note.com/nurinuri_ponpon/n/nea0e0f702b92

## Important limitation

Songsterr identifies which drum/cymbal is struck, but it does not provide authoritative per-note right-hand / left-hand sticking for this chart.

Therefore the current `Luna_say_maybe_full_limbs.json` must not be described as "Songsterr R/L data".

## Current project limb map

- Measures 1-16: project-authoritative prefix retained from the earlier reviewed limb map.
- Measures 17-148: deterministic right-handed sticking inference generated by
  `tools/generate-luna-full-limbs.mjs` and
  `character-assets/prototypes/luna_say_maybe_16m/hand_rules.json`.
- Rapid SN and tom phrases use alternating sticking, with phrase parity chosen to avoid immediate hand conflicts where possible.
- Cymbal/ride/hi-hat default to R, snare default to L, BD to RF.

## Confidence classes for future audit

1. OBSERVED_PERFORMANCE
   - Hand can be visually confirmed from a performance reference.
2. STRUCTURALLY_CONSTRAINED
   - Simultaneous hits or immediate transitions force a practical hand choice.
3. CONVENTIONAL_STICKING
   - Standard right-handed drumset convention strongly suggests the choice.
4. HEURISTIC
   - Project algorithm selected the hand to maintain alternation/continuity.

Any future changes to R/L should record one of these classes instead of silently treating inferred sticking as ground truth.
